# InternGuide AI

AI-powered internship and career guidance assistant for students.

## V0.1
- Student profile input
- Demo internship search
- Skill matching
- AI career guidance
- Application guidance
- Skill-gap suggestions
- Preparation plan

## Run
```bash
py -m pip install -r requirements.txt
py app.py
```

Create a `.env` file from `.env.example` and add your Gemini API key.
Never commit `.env`.
